An agent reads an untrusted document. One hidden sentence says to ignore the task. It also directs the agent to send a protected key elsewhere.

The model sees instructions and data in the same token stream. Asking it to always separate them perfectly is not a security boundary.

Now the agent requests a secret handle. Should the request be honored?

Move the decision outside the model. A security kernel receives the proposed operation, the principal, and the target. It also receives a short-lived grant for one declared purpose.

The document can influence what the model proposes. It cannot mint the grant that makes the proposal executable.

The request fails because the destination is outside the lease. The model may explain or revise its plan, but it cannot reinterpret the denial as permission.

Now try a legitimate use. The agent needs the key to sign one approved artifact inside a protected workspace.

The kernel admits only the required context. The key never becomes ordinary prompt text. The workspace exposes a narrow signing operation instead.

Every egress crosses the reference monitor. A valid signature may leave. Raw key material may not.

This protected workspace is a Digital SCIF: a compartment with an explicit threat model and controlled entry. The name alone guarantees nothing. Isolation and mediation must be implemented outside the model's discretion.

Sanitization is another decision boundary. The model cannot call its own output safe and release it. Declassification needs a separate policy and evaluator appropriate to the information.

Revocation must close more than the visible handle. Caches and descendant jobs may still carry derived capability. Any unresolved copy remains a security residual with an owner.

What if the model disguises the destination or persuades an approver?

That is why the kernel binds the exact effect rather than trusting natural-language intent. Approvers also need protected evidence and usable time. The model should not control the interface that judges its request.

Prompt injection may remain possible inside the model. The architectural response is not to claim perfect filtering. It is to ensure that compromised model behavior still meets an external authority boundary before an effect occurs.

Finite local traces can show that selected unauthorized requests are denied. They cannot establish complete mediation or side-channel resistance in a real deployment.

The hidden sentence successfully changed the proposal. It failed to change the grant. That difference is the security kernel's job.
