A toy image classifier performs well on clean test data. Add a small patterned patch, and one object is routed to the wrong class.

Did the model become inaccurate, or did the threat model change?

Clean accuracy measured ordinary inputs. The patched case introduces an attacker who can alter the input while preserving the object's meaning.

Security evaluation begins by naming that attacker. Record what the attacker can observe. Fix the attempt budget and identify which lifecycle stage can be influenced.

Freeze the exact model version and the attack budget. Now the result has a denominator.

Apply a detector that blocks the first patch. The dashboard turns green. Is the model robust now?

Not if the threat model allows adaptation. An attacker who can observe the defense may search for a different pattern. A static test can overstate protection by freezing the adversary while changing the defender.

Run the adaptive challenge. Preserve failed attempts as well as the successful one. Otherwise a defense can appear cheap by hiding the search cost or appear strong by hiding the attack budget.

Keep clean utility visible. A detector that rejects every image may stop the patch, but it has destroyed the service it was meant to protect.

Recovery matters too. When an attack is detected, can the system isolate the affected route and restore a trusted model state? Detection without a response path may only produce a better incident report.

Now move to training time. A poisoned example or hidden trigger enters through a different surface. The input-time result cannot automatically transfer.

Extraction and privacy attacks differ again. They need their own objectives and observations. One overall robustness score would hide which surface was actually tested.

The model-threat record therefore stays versioned by model and lifecycle stage. It also records the attacker's access and the effect that was observed.

When the model or defense changes, the old result may expire. The same is true when the attacker receives more queries or tools.

Public toy models can support safe evaluation of this machinery. They do not establish robustness for frontier systems or production environments.

Formal certificates can be valuable inside a bounded perturbation model. They do not certify every attack surface or every downstream effect.

The patch makes the useful lesson visible. No single defense simply wins. A security claim becomes meaningful only after the attacker and tested surface are explicit. Adaptation and utility must remain on the same ledger.
