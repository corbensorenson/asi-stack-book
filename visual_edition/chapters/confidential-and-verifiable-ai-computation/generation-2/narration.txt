A user wants an AI provider to process a private document. The user wants to hide the input. The provider wants to protect the model. Both want evidence that the approved computation ran.

Transport encryption is not enough. The data must become usable somewhere, and that execution boundary needs its own contract.

Place the inference inside a confidential environment. The user encrypts the input for that environment. The provider loads a committed model artifact.

Before releasing the input, a verifier checks an attestation. The attestation names the measured software and the platform state. It also carries a freshness value.

Suppose the signature is valid but the measurement names yesterday's model. Should the input be released?

No. A valid attestation can still describe the wrong artifact. Cryptographic authenticity is not semantic correctness.

Bind the model and preprocessing code into the statement the verifier expects. Bind the current policy and epoch too.

Now replay an old attestation after revocation. The bytes are authentic, but freshness fails. The environment does not receive the input.

The execution succeeds on the current artifact and returns a signed result. What has been established?

Only the named guarantee. The verifier has evidence about a measured environment and a committed computation. It has not proved that the model's answer is true or that the purpose is lawful.

Confidentiality also needs a leakage model. Output length and timing may reveal information. Logs or access patterns may expose more than the encrypted payload suggests.

Different primitives protect different properties. A zero-knowledge proof may establish a relation without revealing a witness. Secure multiparty computation divides trust. Fully homomorphic encryption changes the execution model again.

No single "secure compute" label can stand in for all of them.

Cost belongs beside the guarantee. A protected route that is unusably slow may force operators into an ungoverned fallback.

Recovery matters when verification fails. The system can choose a narrower route or abstain. It cannot silently drop the requested guarantee to preserve throughput.

A local demonstration can test replay and artifact mismatch. It cannot establish side-channel resistance or end-to-end privacy in deployment.

For the private document, the useful result is a precise statement about which artifact ran under which trust assumptions. That statement is valuable because it refuses to become a claim about everything else.
