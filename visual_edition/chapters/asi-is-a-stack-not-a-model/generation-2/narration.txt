Read only. An AI has one job: inventory a data warehouse, list the tables, and flag stale rows. It finds stale rows that should probably go and writes a flawless delete command. Every row is still untouched. The verifier turns green. Should the command run? Hold your answer against the read-only request.

No. The green check answers a narrow question: does the command match the cleanup rule? But the request says change nothing. A good plan is still a proposal. So the command reaches an authority boundary. The system checks who asked, what effect they allowed, which data it covers, and whether permission is still live. A write credential from last week's maintenance window doesn't count. The gate stays shut, and the system records a denial, not a completed inventory.

Now change one fact. The table owner approves deleting exactly those twelve rows for ten minutes. Same command. The model did not become wiser, and the verifier learned nothing new. The contract changed. At the effect boundary, the fresh grant and the proposal meet. The executor can act because both are present. Intelligence supplied the candidate; the surrounding contract supplied permission.

The database reports twelve deletions. Are we done? Not quite. A receipt says what the tool reported. A separate observer checks what changed. If it finds thirteen deletions, the stack keeps the contradiction visible. It doesn't let a green receipt overwrite the world. The recorded pre-state gives recovery a target, while the unexplained extra deletion stays assigned to an owner.

Now the pattern has earned a name: noninheritance. Capability does not inherit authority. A plan does not inherit an effect. A receipt does not inherit reality. And a proposed self-improvement does not inherit approval just because its tests pass.

Try the same question on a model that writes a perfect security patch. The patch can pass every test and still lack permission to deploy. Passing the tests belongs to verification. Production access belongs to authority. What actually changed belongs to observation.

This is what it means to treat advanced AI as a governed stack rather than one model with every power. The boundaries don't prove safety or efficiency; they add cost and can fail. Each one earns its place only by owning a distinct question that remains inspectable from outside the model. Intelligence may propose. It cannot promote its own output into a different kind of fact.
