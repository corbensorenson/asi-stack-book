# Generation 2 storyboard — ASI Is a Stack, Not a Model

Status: `scripted`; animatic not yet accepted.

Teaching promise: the viewer can predict why a capable model still needs a
governed system before its output may become an effect.

Final narration duration: `230.230` seconds.

Semantic beats: `27`

This is a complete replacement concept, not a motion pass over generation 1.
The canonical chapter remains at `Design rationale` / `argument`; the video is
a derivative explanation and cannot move support.

## Visual thesis

One cyan request token travels through a glass-workbench machine. A small
luminous model core can create an excellent proposal, but the token cannot
reach the file effect until a separately constructed gold authority key opens
the gate. A copper receipt, green observer lens, magenta residual loop, and red
rollback thread remain independent throughout the trace.

The signature frame is the model inside the wider transparent machine: the
delete token is stopped at the gold gate, while observation and rollback stay
visible as different rails. The final frame returns to the same file case with
all four missing controls separately inspectable.

## Story arc

1. **Concrete hook — 00:00–00:15.** A model finds twelve duplicate files and
   writes a correct delete command. The token moves toward the drive and stops.
   The viewer must decide whether correctness is enough.
2. **Reveal the real machine — 00:15–00:56.** The camera pulls back from the
   model. Context, verification, authority, execution, observation, evidence,
   and recovery assemble around it. They then collapse into an opaque sphere
   so the loss of addressable boundaries becomes visible.
3. **Rebuild around one request — 00:56–01:29.** The request returns with typed
   constraints. Planning branches without acting, permitted context mounts,
   and the verifier attaches an unresolved residual.
4. **Prediction and governed effect — 01:29–02:18.** Motion settles at the
   authority gate. After a real pause, a scoped key is assembled. The adapter
   rechecks it, the exact files change, observation disagrees with the receipt,
   and the recorded pre-state provides a rollback path.
5. **Noninheritance transfer — 02:18–02:52.** The camera reveals the complete
   route. Six attempted inferences stop at stable gates, then a proposed model
   replacement remains separated from its approval and certification keys.
6. **Strong objection and fair test — 02:52–03:20.** Interface costs weigh on
   the rails. A monolith, wrapper, and stack receive matched inputs while six
   evaluation counters move together. No winner is shown.
7. **Evidence ceiling and payoff — 03:20–03:50.** A double rule encloses the
   finite local trace. Broad claims remain outside. The opening delete case
   returns, now surrounded by separately visible authority, observation,
   residual, and rollback objects, before flowing into the efficiency question.

## Composition and motion rules

- Keep the request token and authority gate spatially stable across the middle
  two minutes; transform and extend the world rather than clearing it.
- Use short labels beside objects. Narration carries causes and consequences.
- Each narrated beat gets a visible onset and resolution within its measured
  audio interval. The final state settles before the next causal idea begins.
- Use linear motion for request flow, ease-out for arrivals, ease-in for firm
  stops, and ease-in-out for transformation and motivated camera reframing.
- No ambient drift, decorative particles, bouncing, flashing, shake, spin, or
  continuous zoom. No card grid replaces the persistent world.
- The prediction beat becomes still on purpose. All other holds must preserve a
  meaningful comparison or allow a completed state change to register.

## Audio and accessibility

The narration is warm and curious, with emphasis on the opening question, the
spoken “No,” the six noninheritance contrasts, the fair-test objection, and the
evidence ceiling. The animatic uses no music. Any later music must be
rights-cleared, sparse, absent under the prediction and evidence boundary, and
at least 20 dB below speech.

Color is always duplicated by shape, position, count, and a short label.
Authority uses a key and gate, evidence a lens and ledger, residuals an open
loop, and rollback a return thread. Exact-receipt captions and the descriptive
transcript must name all material visual state changes. Review includes normal,
muted, audio-only, captions-on, phone, large-screen, headphone, speaker, and
random-frame passes.

The machine-auditable source is `beat_plan.json`; this storyboard explains the
intended whole-video experience but does not supersede that timing contract.
