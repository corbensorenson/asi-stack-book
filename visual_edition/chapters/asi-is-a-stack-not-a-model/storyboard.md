## Required semantic beats

1. Problem: an advanced AI system needs an architecture frame larger than its
   token generator.
2. Core mechanism: governed layers exchange typed artifacts under explicit
   authority, evidence, residual, and rollback contracts.
3. Worked trace: request → plan → context → verification → scoped grant →
   effect → observation → evidence.
4. Strongest failure boundary: interfaces can add latency, brittleness,
   information loss, and governance theater.
5. Current evidence: the chapter core remains at `argument`;
   finite repository checks do not establish the whole stack.
6. Non-claims: no ASI, safety, efficiency, deployment, transfer, or
   architecture-general result.
7. Handoff: the next chapter asks whether the added boundaries improve useful
   work per total governed cost.
