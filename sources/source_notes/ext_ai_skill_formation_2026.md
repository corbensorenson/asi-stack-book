# How AI Impacts Skill Formation

| Field | Value |
|---|---|
| Source ID | `ext_ai_skill_formation_2026` |

Judy Hanwen Shen, Alex Tamkin. [Primary paper, arXiv 2601.20245v2](https://arxiv.org/html/2601.20245v2).

## Thesis

Completing a programming task with assistance and learning to diagnose similar code are different outcomes.

## Mechanisms

Measure assisted completion and later unaided diagnosis for a comparable task.

## Evidence

The assisted group scored 4.15 points lower on a 27-point follow-up quiz about an unfamiliar asynchronous Python library. Average completion-time improvement was not statistically significant.

## Failure Modes

Randomized unfamiliar-library task and subsequent quiz. Observed interaction styles were not randomized treatments. A short study cannot estimate lasting workforce effects.
