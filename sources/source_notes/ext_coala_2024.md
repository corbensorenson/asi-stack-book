## Thesis

CoALA organizes language agents through modular memory, a structured action space over internal memory and external environments, and a generalized decision process. It connects current language-agent designs to cognitive science and symbolic cognitive architectures.

## Mechanisms

- Separate working, episodic, semantic, and procedural memory roles.
- Distinguish internal reasoning and retrieval actions from external environment actions.
- Organize observation, planning, action selection, and learning within an agent decision cycle.
- Use the framework to compare existing agents and identify prospective design directions.

## Evidence

- The source is primarily a conceptual framework and literature organization rather than a qualification system for transferable methods.
- This repository did not reproduce any surveyed agent result or test CoALA as an implementation.
- Use it as direct prior art for cognitive organization, not as evidence for CMTQ's transport or qualification claims.
