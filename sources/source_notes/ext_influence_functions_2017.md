# Understanding Black-box Predictions via Influence Functions

Source ID: `ext_influence_functions_2017`
Source: <https://proceedings.mlr.press/v70/koh17a.html>

Koh and Liang use influence-function approximations to trace predictions
through a learning algorithm to influential training examples. The method can
support debugging and attack analysis under stated assumptions. Approximate
influence is not exact causal provenance, membership proof, privacy erasure, or
proof that removing a point removes its learned effect.
