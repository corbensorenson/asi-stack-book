# Test-Time Training with Self-Supervision

Source ID: `ext_test_time_training_2020`
Source: <https://proceedings.mlr.press/v119/sun20b.html>

Sun et al. update model parameters on each test sample using a self-supervised
objective and report improvements on studied image-corruption benchmarks. The
book uses the method to force inference-time update identity, rollback, and
poisoning boundaries. It does not establish safe adaptation under arbitrary
shift or transfer to language and agent systems.

## Book Chapters Supported

- `governed-model-training-distributed-optimization-and-scaling` (Governed Model Training, Distributed Optimization, and Scaling)
- `replaceable-cognitive-substrates-beyond-transformer-monoculture` (Replaceable Cognitive Substrates: Beyond Transformer Monoculture)
