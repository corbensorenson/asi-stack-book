# C1 Retained-Lineage Comparator and Ownership Map

Recorded: 2026-07-25

## Purpose

The ASI Stack retains memorable project names when they help readers trace an
idea to Corben's source corpus. A retained name is not automatically a new
layer, a normative protocol, an implementation claim, or an evidence class.
This map gives each label one plain comparator, one canonical owner, and one
maximum role so the book can preserve lineage without multiplying ontology.

## Convergence rule

On first use, prose should pair a retained label with its ordinary function:
“PlanForge, the source-lineage planning compiler,” or “Octopus Router, the
source-lineage specialist router.” Later prose may use the shorter label when
the owner is clear. Normative requirements are stated in the owner's generic
vocabulary. Evidence attaches to exact claims and artifacts, never to the
prestige of the retained name.

## Collision and retirement policy

If two retained labels describe the same responsibility, the canonical owner
keeps one generic interface and the labels remain source aliases. If a label
acquires a genuinely distinct contract, consumer, invariant, and failure
boundary, the chapter-consolidation process may grant it an owner. If the name
no longer improves provenance or comprehension, prose should retire it while
preserving source history in the source matrix.

This map changes terminology ownership only. It does not promote a claim,
validate an implementation, certify a comparator, or establish that the
underlying source project achieved its intended result.
