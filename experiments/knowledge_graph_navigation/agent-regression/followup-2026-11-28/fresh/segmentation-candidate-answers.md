# FB2

ByteFlow fixes the number of internal boundary positions that can be selected for a packet of a given length. It learns input-dependent boundary scores, so equally long packets can place their highest-ranked boundaries at different positions. When useful splits outnumber slots, a lower-ranked split can be dropped. Before using these decisions for a literal controller field, test exact recovery of the field and its value against the original packet bytes on the intended workload, including cases where a field boundary falls below the cutoff. Use the source bytes to verify the literal before acting on it. [Replaceable Cognitive Substrates, §55.11.3, fixed boundary budget and controller-identifier example](https://corbensorenson.github.io/asi-stack-book/chapters/replaceable-cognitive-substrates-beyond-transformer-monoculture.html#a-fixed-budget-for-learned-byte-boundaries)

# FB3

A ratio loss helps control chunking pressure. The encoder's selected boundary vectors form the shorter stream, and smoothing, upsampling and residual paths return it to byte resolution for autoregressive prediction. On the same device, compare the incumbent and H-Net on matched raw inputs and a shared quality target, using the service's actual batch sizes and a representative mix of lengths. Measure chunk-count distributions, peak memory, end-to-end latency including its tail, verified outputs per elapsed time and acceptable outputs delivered by the deadline, accounting for fallback. Keep the incumbent if H-Net delivers fewer acceptable outputs by the deadline despite processing fewer deep-stage positions. [Replaceable Cognitive Substrates, §55.11.2, H-Net §§2.1–2.4, 3 and 4](https://corbensorenson.github.io/asi-stack-book/chapters/replaceable-cognitive-substrates-beyond-transformer-monoculture.html#h-net-learns-the-sequence-hierarchy)

# FB4

The authors report that a 109M-parameter text JEPA surpassed the evaluated language models, which ranged up to 72B parameters, on specified representation-alignment measures. The conditional theorem assumes an identity predictor. The practical experiments used LeJEPA under conditions that departed from the theorem's hypotheses. The alignment result leaves task-preserving replacement of a text-generating specialist unresolved. Compare the candidate with the incumbent on the specialist's actual end-to-end tasks and hold the downstream decision rule fixed when testing whether the representations preserve distinctions that change the correct outcome, such as differing authorizations. [Replaceable Cognitive Substrates, §55.11.1, Platonic JEPA §§2.1–2.3, 4.2–4.3 and 7](https://corbensorenson.github.io/asi-stack-book/chapters/replaceable-cognitive-substrates-beyond-transformer-monoculture.html#jepa-is-a-prediction-objective-not-a-complete-agent)
