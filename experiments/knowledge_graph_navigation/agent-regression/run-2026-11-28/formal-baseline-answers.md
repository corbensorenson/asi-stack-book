# FO3

`participation_signals_cannot_recover_representation` says that a classifier receiving only the modeled participation signals cannot recover the correct representation state in every authored case. Two cases have identical observations and different representation states. A classifier restricted to those observations must return the same answer for both, so it misses at least one. This is a non-identifiability result for the finite model. Whether a real institution is representative or legitimate remains an empirical and institutional question. Pooled coverage is (87 + 5) / (90 + 10) = 92%. Camera-only coverage is 5 / 10 = 50%. If those ten frames are from one maneuver, the 50% describes the frames from that episode. They provide little evidence about a separate episode. Modality-conditioned coverage assumes exchangeability of calibration and test points within the modality group.
