# FO3

`participation_signals_cannot_recover_representation` rules out perfect recovery across all `RepresentationCase` values in the finite model by a Boolean classifier that sees only `c.signals` of type `ParticipationSignals`. Two modeled cases can expose identical signals while differing in `RepresentativeEnough`. A classifier must return the same output for identical input, so it fails on at least one of those cases. The proof establishes an information limit under the modeled observation restriction. Whether a real institution is representative or exhibits the same ambiguity requires empirical evidence. # FO4

Pooled coverage is `(87 + 5) / (90 + 10) = 92%`. Camera-only coverage is `5 / 10 = 50%`. If all ten camera-only frames come from one maneuver, that 50% describes the frames in a single episode. Their errors can be correlated within that episode, and camera-only operation can be tied to difficult maneuvers if vibration disables the encoder. The conformal group guarantee assumes exchangeability of calibration and test points within a sensor-availability group. Estimating performance on a new maneuver requires separate representative episodes and a coverage metric defined at the decision unit.
