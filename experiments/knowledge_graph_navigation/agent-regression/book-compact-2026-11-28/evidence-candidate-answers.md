## BE3

With the primary withheld before dispatch and the caller aware of that, direct fallback skipped the primary read. Both arms achieved 8/8 verified closures using 8 caller requests each, so the gateway saved zero caller requests. The gateway added 2,033 HTTP response bytes per verified fallback across both hops. The study used a loopback gateway on one host in one time window, with delivery services sharing an npm origin. All actual reads succeeded, and the transport counts exclude TLS and human labor. Rerunning the command would collect a fresh live network observation. The pinned raw result preserves the original snapshot.
