## BR1

A reviewer can have the right qualifications and still lack the capacity for this assignment. Their workload may be too high, they may lack the relevant repository history or depend on the producer’s summary, or the deadline may leave too little time to inspect the work. The scheduler records workload, context, relevant qualification, dependence, time, tool and model limits, uncertainty, and required supervision. The worker can accept, narrow, defer, request assistance, or decline. Extra reviewers provide independent checks only when their routes can detect meaningfully different failures. Three agents using the same model and context or three overloaded humans reading the same compressed packet can share the same blind spots. The assignment record should expose relevant shared models, data, prompts, supervisors, incentives, and tools. ## BR2

A signed build and a current grant suffice for approval. Adding “the log is blue” still earns full credit from the sufficiency proxy, while the exact process checker rejects the spurious reason. In the published rule-based task the proxy reached **0.940** and exact faithfulness fell to **0.667** across **96 held-out episodes**. The example calls for holding the update when the exact score deteriorates. This result is scoped to a task with rules that let an oracle judge which reasons belong in the explanation. Open-ended preferences rarely provide such an exact oracle. ## BR3

On one B200, Qwen3-32B used approximately **95 GPU J per conversational response** at batch 512 and **2,200 GPU J per problem-solving response** at batch 128 (reported as 2,192 J). At the common batch size of **128**, the respective rates were **0.209** and **0.312 GPU J per output token**. Task mix and generation mode varied together. To isolate the mode change, run the same questions in both modes under the same batching conditions, acceptance criteria, and latency limit. Divide metered energy across all attempts, including failures and retries, by accepted answers. Cooling belongs in the facility energy calculation, outside the GPU measurement. Use the local electricity supply when translating facility electricity into emissions.
