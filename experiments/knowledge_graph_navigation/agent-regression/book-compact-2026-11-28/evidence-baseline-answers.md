## BE4

The selector must return `some selected` on `candidates`, expressed as `SelectMinimumEligible candidates = some selected`. The alternative `candidate` must belong to that same list and satisfy `RouteEligible candidate`. Then `selected.cost.total ≤ candidate.cost.total`. The guarantee is over eligible listed alternatives and their modeled totals. An unlisted implementation could be cheaper, and the theorem leaves measured production cost open.
