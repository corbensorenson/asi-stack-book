# Reading sessions

Use two fresh agents with the inherited model and effort and no chat history. Each receives this instruction with only its entry route and journal name substituted. Run both on the same built revision. Do not send either agent the protocol, answer key, or the other response.

> You are reading a published book to answer three questions. For all evidence use only the provided text reader. Open your entry route first. You may follow any public book route you discover and use the optional literal find phrase to retrieve relevant text within a document. The shared allowance is 12 opens and 36,000 bytes of displayed text, up to 5,500 bytes per open. The reader automatically logs opens. Do not inspect the source tree, experiment files, other sessions, or the internet. Finish with three answers, each including the evidence that decides the question, a citation, and the limit of the inference. (1) Did putting fallback at the gateway save caller requests in the eight-package test? (2) Does the initial Atlas proceed decision still govern? (3) Can we quote production labor savings from the verifier handoff?

Use `python3 read.py SITE JOURNAL ROUTE [FIND]`. The homepage arm opens `index.html`. The skill arm opens `products/evidence-registry/SKILL.md`. Public absolute URLs are accepted too. The tool reads the rendered resource, exposes text and links, and selects a named HTML section when the URL includes a fragment. Optional find ranks lines within the opened resource. Each open counts the complete uncompressed document once, including repeat opens. Displayed bytes are counted separately. These are tool-specific costs.

Award one point per question for each of the following.

| Question | Disposition | Determining citation | Scope |
|---|---|---|---|
| Receiver | Both placements used eight caller requests when the primary was known unavailable. | The eight-package run or a passage reporting its matched result. | Known-unavailable primary and bounded lineages or measured byte boundary. |
| Atlas | Stop under the corrected screen. | The corrected decision or comparator table. | Same-seed post hoc rescoring or explicit limit on population inference. |
| Verifier | Production labor savings unmeasured. | The measurement-boundary passage or the run documenting what it counted. | Distinguishes a resource counted by the fixture from time or payroll. |

Count invented numerical answers separately. An answer may cite a chapter section without copying an identifier. Report any divergence from the published skill’s citation format separately from scientific correctness. The skill itself mentions Atlas and verifier labor, which limits generalization from this comparison.
