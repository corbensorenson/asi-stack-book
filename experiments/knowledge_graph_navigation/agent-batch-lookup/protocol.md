# Repeat the five-question agent retrieval comparison

Reuse the exact questions and rubric from the direct-section comparison. The 115.2 repair lookup and GPU energy lookup informed this change. This is a repeat of a previously held-out set and measures whether those misses recur with fresh agents. It provides no new out-of-sample estimate.

Compare the original published baseline (db8d094d0871b6d73ade3e89ab95649448a5c070), the published direct-links edition (d5d8c2f7c11985af1a7f9a4393f0771745610639), and the newly deployed lookup edition. Use 2 fresh independent sessions per edition, the same inherited model and reasoning configuration, and the tested publication artifacts. Each agent starts at the homepage and receives the same five questions and reader invocation. Allow 18 opens and 52,000 displayed bytes per session, with at most 5,500 bytes per open. The common reader accepts ordinary lookups or several explicit clues in one catalog open. The batched action uses the shipped ranker and charges the entire uncompressed catalog once. Agents discover resources through the assigned edition. The comparison uses the same reader for all three arms. The reader in the previous comparison did not have a batch action.

Grade the three fields per question with the prior rubric. Report results for each session. Report whether both new-edition sessions recover the repair threshold and explicitly reject extrapolating the Dory speedup to the cache policies. Parity requires a total at least that of both current baselines, two evidence-backed cache abstentions, and no unsupported numerical claims. The cost gate requires no more than the direct-links arm's cumulative and deduplicated bytes and no more than half the original baseline's bytes. Count repeated discovery reads beyond the first read of each catalog, within a session, and sum across each edition. Report the number of opens, bytes, and displayed bytes used even when scores tie. The authoring agent grades with knowledge of the edition. Six sessions on these five known questions are descriptive. Network compression and billing are outside the observation.
