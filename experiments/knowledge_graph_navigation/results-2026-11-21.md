# Knowledge graph navigation comparison

The final local comparison covered twenty authored tasks. The graph found
the exact destination on 20 of 20 tasks, compared with 19 of 20 through
Quarto search and the Evidence Registry. It found the destination within
the four primary results on 15 tasks, compared with 8. Both interfaces
returned the correct limit from the same study run on all five limit cases.

The runner collected 160 existing-route records with 72,998 UTF-8 bytes
of excerpts and 111 graph records with 24,118 excerpt bytes. These are
retrieval excerpts. Actual network use includes indexes, shards, pages,
and other assets. The existing appendix Reader link returned a 404 on
seven followed routes. Those responses remain in the report. No trial
stopped on a browser error.

## Coverage and limits

The tested snapshot contains 5,683 nodes and 47,461 typed links. It covers
89 technical chapters, 26 Reader units, 168 concepts, 594 sources,
4,247 claim identities, 84 retained claim records, 344 proof targets,
115 transition records, and eight runs across four studies. Sixty source
records link directly to their published manuscripts. The unresolved
list includes 1,685 retained claim dependencies and 87 source chapter
references with no corroborated current chapter.

This comparison uses a single authored task set and one local render.
It measures destination retrieval and five limits from retained study
runs. The graph reached many records earlier on this set. Both interfaces
preserved the five tested evidence limits. The scope leaves open results
for independent readers, agent answer quality, and time savings.
